# Elektro jednoduše

Interaktivní český kurz k učebnici **Elektrotechnický základ** od SOŠ elektrotechnické v Hluboké nad Vltavou (2011).

## Co stránka obsahuje

- úvod do značek a jednotek SI,
- osm kapitol vysvětlených běžnou češtinou,
- příklady a otázku s vysvětlením v každé kapitole,
- animaci elektrického obvodu a sinusového průběhu,
- malou laboratoř pro Ohmův zákon,
- vyhledávání, tahák vzorců, slovníček a ukládání postupu v prohlížeči,
- samostatnou bezpečnostní část podle aktuálních doporučení Českého červeného kříže a záchranné služby.

## Otevření

Otevři soubor index.html v prohlížeči. Stránka nepoužívá žádný server ani knihovnu třetí strany.

## GitHub Pages

Nahraj soubory index.html, styles.css, lessons.js, app.js a .nojekyll do kořene repozitáře. V nastavení repozitáře otevři **Settings → Pages** a zvol nasazení z větve main a složky root. Po dokončení GitHub zobrazí adresu stránky v nastavení Pages.

## Zdroj učiva

Původní učebnice: [Elektrotechnický základ (PDF)](https://sosehl.cz/uploads/2020/11/Elektrotechnicky_zaklad_ucebni_text.pdf).

Text výkladu a procvičovací příklady jsou nové studijní zpracování. Bezpečnostní postupy vycházejí z [aktuálních Standardů první pomoci Českého červeného kříže](https://www.cervenykriz.eu/standardy-poskytovani-pp) a doporučení [ZZS Praha](https://www.zzshmp.cz/prvni-pomoc/).
